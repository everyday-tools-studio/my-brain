# Security reports · Signalements de sécurité

## English

On the repository’s **Security** tab, use **Report a vulnerability** if available. If that option is unavailable, ask a maintainer for a private channel in an issue using only the words “Private security contact requested”. Wait for the channel before sharing details.

Include the app revision, affected platform and a description using synthetic data. Pairing QR codes grant access to synced items. Keep QR codes, access tokens, message contents, backups, keys and addresses out of public issues and screenshots. To revoke device access, run `python3 cerveau.py unpair-all` on the PC using the affected profile and pair your trusted devices again.

## Français

Dans l’onglet **Security** du dépôt, choisis **Report a vulnerability** si ce bouton est disponible. Sinon, ouvre un ticket intitulé « Demande de contact privé pour un signalement de sécurité ». Attends de recevoir le canal privé avant de transmettre les détails.

Indique la révision de l’application, la plateforme et les symptômes avec des exemples fictifs. Un QR code d’appairage donne accès aux éléments synchronisés. Garde les QR codes, jetons, messages, sauvegardes, clés et adresses hors des tickets publics et des captures d’écran. Pour révoquer les appareils, exécute `python3 cerveau.py unpair-all` sur le PC avec le profil concerné, puis associe à nouveau les appareils de confiance.
